# 耐力

耐力让连续行动产生取舍，但耗尽后仍能移动。

## 基础数值

| 项目 | 当前默认值 |
|---|---:|
| 最大耐力 | 100 |
| 基础恢复 | 每秒15点 |
| 费力动作后的恢复延迟 | 1秒 |
| 力竭后的恢复延迟 | 2秒 |
| 力竭解除阈值 | 恢复至30点 |

基础恢复会受到负重、口渴、体温和其他状态影响，不应直接当作所有环境下的净恢复。

## 常见消耗

| 动作 | 基础消耗 |
|---|---:|
| 走路 | 每秒1.5 |
| 疾跑 | 每秒8 |
| 普通跳跃 | 每次5 |
| 疾跑跳跃 | 每次7 |
| 挖掘 | 每秒2 |

近战只有击中实体时才按当前实现扣除，不把草案中的挥空消耗当作现行规则。开镜保持的草案消耗也未实现。

## 力竭

耐力到0后进入力竭，暂时不能疾跑，并影响近战、挖掘与枪械稳定性；恢复至阈值后解除。负重越大，连续高强度行动越难维持。

## 验收范围

耐力 V1 基础机制已有实机验收记录（2026-10-03）。这不代表所有服务器、整合包或后续 HUD 变化均已验收。
