# 内容状态说明

每页状态说明该条目核实到了哪一步，不能把开发规划当作已经发布的功能。

| 状态 | 含义 |
|---|---|
| 已实机验收 | 存在明确的实机验收记录，仍需阅读具体范围 |
| 已实现 · 待验收 | 实际代码或数据已存在；未确认完整实机验收 |
| 规划中 | 设计目标或后续内容，不作为当前可用功能 |
| 已废弃 | 已停止使用的旧说明，不应继续指导当前版本 |
| 资料待核实 | 本 Wiki 尚未完成独立核对，不推定游戏功能不存在 |
| 栏目索引 | 导航或项目说明，具体功能看对应条目 |

## 已废弃说明示例

**“TaCZ 是 AFL 当前正式硬前置”属于已废弃说明。** 当前框架与前置以[游戏基础](../guide/basics.md)和[下载与版本](download.md)为准。

## 数值与图片

数值来自已核实的当前默认配置，但仍可能调整。枪械示例复用 AFL 现有物品图，并明确标注为物品图。未提供的正式截图保留占位，不伪造游戏画面。

## 公开内容边界

本站只整理玩家所需资料，不默认公开内部任务记录、调试工具、私人存档或敏感开发信息。
