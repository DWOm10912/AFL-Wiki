# 如何阅读武器属性

先区分基础数据与战斗中的最终结果。

| 属性 | 含义 |
|---|---|
| 基础伤害 | 当前配置的身体基础伤害，不等于所有距离、护甲下的最终伤害 |
| 基础弹匣容量 | 未安装有效扩容附件时的容量 |
| 射击模式 | 枪械允许的扣扳机方式，不代表不同模式的间隔完全相同 |
| 衰减起点 | 伤害开始随距离降低的位置 |
| 标称有效射程 | 说明性数据，不直接等同于命中判定 |
| 最大射线距离 | 射击追踪的距离上限 |

## 开发版数值

Wiki 表格是一次人工核对后的默认数据快照，不与游戏实时同步。服务器数据包或后续更新可能改变这些值。
