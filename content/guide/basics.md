# 游戏基础

先确认游戏环境，再开始配置你的生存世界。

## 当前环境

| 项目 | 核实信息 |
|---|---|
| Minecraft | 1.20.1 |
| 加载器 | Forge，当前开发配置为 47.4.22 |
| Java | 17 |
| AFL | 1.0.0-alpha 开发版本标识 |
| Mod ID | `apocalypse_firstlight` |

## 前置与可选扩展

当前模组元数据声明 GeckoLib、TerraBlender、Curios 为必需依赖。确切兼容范围见[下载与版本](../project/download.md)，安装时应使用同一发布包说明的版本。

**AFL 使用自己的原生枪械框架，TaCZ 不是当前正式硬前置。** 不要用旧枪械教程推导现在的依赖要求。

## 第一次进入

1. 阅读版本说明；开发版测试建议新建世界，并为已有存档保留备份。
2. 打开“选项 → 控制”确认按键冲突。下文默认键位可能已被你或整合包改动。
3. 先了解[负重](../survival/weight.md)、[耐力](../survival/stamina.md)与[口渴](../survival/thirst.md)，再安排携带物品和行动距离。

获取武器、机器的生存配方与战利品来源尚未逐项核实，本站不会把创造物品列表当作生存获取指南。
