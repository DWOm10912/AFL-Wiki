# 常见操作

以下是 AFL 原生枪械的默认键位。以游戏“选项 → 控制”中的实际绑定为准。

| 操作 | 默认输入 |
|---|---|
| 射击 | 鼠标左键 |
| 瞄准 | 鼠标右键 |
| 换弹 | R |
| 切换射击模式 | B |
| 检视武器 | V |
| 打开野外配件视图 | Z |

## 使用提示

- 只有枪械支持的模式才能切换。P9-01 与 BR-51 当前都支持半自动和全自动。
- `V` 是检视，不能套用旧教程中的快捷安装操作。
- 配件必须与枪械兼容；详情见[枪械配件](../weapons/attachments.md)。
- 按键没反应时，先检查是否与其他模组冲突，再确认当前是否处于能执行该操作的状态。
